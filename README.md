# 🧠 LEETCODE_DP

Welcome to **LEETCODE_DP**, a curated collection of daily LeetCode problems focused on **Dynamic Programming (DP)**. This repository is maintained by [Aditya792max](https://github.com/Aditya792max) and serves as a personal log of problem-solving, learning, and growth in one of the most challenging areas of algorithmic programming.

## 🚀 Purpose

Dynamic Programming is a cornerstone of competitive programming and technical interviews. This repository aims to:

- 📘 Document daily DP problem-solving efforts
- 🧩 Explore various DP paradigms (memoization, tabulation, space optimization)
- 🛠️ Share clean, readable, and optimized solutions
- 🧠 Strengthen understanding through consistent practice

## 📂 Structure

Each problem entry typically includes:

- ✅ Problem name and link to LeetCode
- 💡 Problem description and constraints
- 🧠 Approach and thought process
- 🧪 Code implementation (JAVA only).
- 📈 Time and space complexity analysis
